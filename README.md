# Proy_SW505_2026_2_grp_3
Proyecto de un : Sistema de autorizaciones y concesiones de transporte terrestre de ámbito nacional
## Descripción del proyecto

Aplicación para gestionar los trámites de autorización de transporte terrestre de mercancías de ámbito nacional ante el Ministerio de Transportes y Comunicaciones (MTC).

El sistema contempla el registro de empresas transportistas, vehículos y conductores, así como la presentación y seguimiento de solicitudes de autorización inicial, renovación, modificación, incremento y sustitución vehicular.

El personal del MTC podrá evaluar solicitudes, registrar observaciones, revisar subsanaciones y formalizar decisiones mediante resoluciones. También se contempla la recepción de actas remitidas por SUTRAN para su evaluación y el seguimiento de la vigencia de las autorizaciones.

El proyecto se desarrolla como parte del curso **Construcción de Software I** de la **Universidad Nacional de Ingeniería**.

## Beneficios de la aplicación

- Organiza los datos de empresas, vehículos, conductores, solicitudes y autorizaciones.
- ermite consultar el estado de las solicitudes y conocer las observaciones pendientes.
- Conserva los antecedentes de evaluación, subsanaciones y decisiones administrativas.
- Facilita la identificación de autorizaciones y acreditaciones vencidas.
- Asigna permisos a los usuarios de acuerdo con sus funciones.
